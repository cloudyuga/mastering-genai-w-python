# 🧠 How Generative AI Works (Simplified View)

A non-technical walkthrough of what's actually happening under the hood of an
LLM — tokens, embeddings, transformers, prompting vs. programming, and where
foundation models like GPT, LLaMA, and Claude run (local vs. cloud vs.
private).

---

## 📊 Slides

Maintained as a Canva design ("Module 2: How Generative AI Works"). Covers,
in order: LLMs as a language-specific subset of foundation models → tokens
and embeddings → transformers at a glance → prompting vs. programming →
where models run → APIs vs. open source → a detailed prompt engineering
section (CRISPE framework, zero/few-shot, chain-of-thought, best practices).
