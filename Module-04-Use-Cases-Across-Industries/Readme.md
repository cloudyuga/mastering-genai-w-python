# 💼 Use Cases Across Industries

GenAI applied to real business functions — HR, Customer Support, Marketing &
Sales, and Product — organized by business function rather than industry
vertical, each paired with a real, sourced case study in the slides.

---

## 📊 Slides

Maintained as a Canva design ("Module 4: Use Cases Across Industries"). Four
sections (HR, Customer Support, Marketing & Sales, Product), each with a
short set of use cases plus a case-study slide with a clickable source link.
